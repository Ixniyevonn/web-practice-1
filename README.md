# Савва Крупницкий — портфолио-кодекс

Одностраничное портфолио-резюме на **SvelteKit** со статической сборкой (**SSG**). Первый экран — светлый техничный «чертёж» с синим акцентом и фотографией в дуотоне. Сразу под ним — отдельная форма для веб- и геймдев-задач, чтобы не проходить портал ради рабочего контакта. Дальше последний экран лобби закрепляется, а поверх него раскрывается рунический портал: фиксированный WebGL-оверлей рассыпает старый экран на полосы, динамическая линза с backdrop-фильтром показывает и растворяет старое, затем увеличивает и открывает **тёмный кодекс** с хроникой, гримуаром навыков, карточками-артефактами и миром Нихерии. Кодекс остаётся тёмным в обеих темах; светлая тема относится к «чертежу» и лобби, а портал ведёт в тёмный мир. Руны и шрифты взяты из проекта Niheria (gloat-svelte).

## Что внутри

- Первый экран минимум на `100svh`: имя, роль, статус, фото, CTA и индикатор скролла.
- Отдельная форма **«Веб и геймдев»** до портала: тема запроса, имя, контакт, сообщение, честная демо-проверка.
- Scroll-driven переход: последний экран лобби закрепляется (`position: sticky`), старый контент рассыпается на полосы и растворяется, настоящие руны Niheria вращаются в двух кольцах, динамическая линза с backdrop-фильтром и стеклянным бликом увеличивает старое и новое, WebGL-шейдер добавляет золотую пыль, fallback без WebGL. Тёмная апертура растёт вместе со скроллом и открывает кодекс; в финале скролл блокируется, кодекс закрепляется на своём месте и проявляется линзой — без дёрганья и без дополнительного скролла. Новый дизайн собирается из фрагментов. На узких экранах закрепление лобби отключается, остаётся короткий тёмный runway.
- Пункт **«Главная»** в шапке и мобильном меню: из фэнтези-кодекса возвращает на первый экран через обратную анимацию портала.
- Разделы после портала: «О себе», «Хроника», «Навыки», «Работы», «Мир Нихерии», «Сейчас», «Геймдев и музыка». В тёмном кодексе — Book Antiqua, Nunito и руническая графика gloat-svelte.
- Фильтр проектов: «Все», «Веб-платформы», «Инструменты и игры».
- Светлая и тёмная темы с сохранением в `localStorage`; кодекс остаётся тёмным в обеих, меняется температура и акценты.
- Мобильное меню: `aria-expanded`, закрытие по пункту и `Escape`, focus trap, возврат фокуса.
- Две демо-формы без сервера: «Веб и геймдев» до портала и «Геймдев и музыка» после; валидация и честное сообщение «письмо не отправлено».
- Копирование email в буфер обмена.
- Плавное появление секций через `IntersectionObserver`.
- Поддержка `prefers-reduced-motion`, skip-link, видимый фокус.
- В подвале: «Создано с помощью DeepSeek» и список реализованных функций JavaScript.

## Стек

- SvelteKit 2 + Svelte 5 (runes)
- TypeScript
- Vite
- `@sveltejs/adapter-static`
- WebGL (raw shader, без сторонних библиотек)
- CSS: токены, две темы, Book Antiqua / Nunito / Inter / JetBrains Mono

## Публикация на GitHub Pages

Сайт рассчитан на репозиторий **`web-practice-1`**, поэтому base path — `/web-practice-1`.

1. Создайте репозиторий `web-practice-1` на GitHub и загрузите содержимое папки `practice1`.
2. В настройках репозитория: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Запушьте в ветку `main`. Workflow `.github/workflows/deploy.yml` соберёт сайт с `BASE_PATH=/web-practice-1` и опубликует папку `build`.
4. Сайт откроется по адресу `https://<username>.github.io/web-practice-1/`.

Локальная сборка под GitHub Pages:

```bash
npm run build:pages
npm run preview:pages
```

Если репозиторий или имя пользователя другие, измените `BASE_PATH` в `package.json` и в workflow. Для собственного домена в корне репозитория base path можно убрать (`BASE_PATH` не задавать).
